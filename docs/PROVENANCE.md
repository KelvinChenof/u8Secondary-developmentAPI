# 源码来源及版本基线

整理时间：2026-10-09。

- U8 源码来自维护工作区 `原维护工作区`，对应已部署的硬编码清理及异常链诊断增强版本。
- OA 扩展、审核回调和独立同步任务从当前 OA 服务器只读导出，并按原始 SHA256 校验。
- 本机旧 `eoffice/server/ext/u8open` 为历史桥接方案，与线上直接调用原生接口的版本不同，没有作为本仓库权威来源。
- 旧一次性单据恢复程序不属于当前运行链，未混入本仓库。

当前版本由维护源码及线上 OA 导出整理后独立脱敏，不包含原始提交历史和生产二进制哈希。`source-inventory.json` 记录公开副本的源码路径及校验值。整理过程只调整业务源码注释及换行，部署脚本的预期旧版/新版哈希改为显式参数，并使用候选哈希区分备份目录。

仓库未提交编译产物。重新编译可能因编译器、路径及注释而产生不同 EXE 哈希，应以实际构建及目标环境的校验值为准。

当前公开及完整版本均需通过 `tools/Test-Repository.ps1`：C# 核心 59 项、资源 8 项、工作进程 14 项、主机 14 项、OA 信封 6 项、历史订单上下文 4 项、部署任务选择 4 项、部署流程 6 项，共 115 项；另做 PHP 语法、PowerShell 解析、OA 校验清单和 x86 构建/启动自检。所有测试使用模拟数据，不调用生产 U8 或 OA 数据库。

用友 SDK 为厂商依赖，不授予额外许可。本仓库由使用者从有授权的本机环境导入 DLL，DLL 被 Git 忽略。
