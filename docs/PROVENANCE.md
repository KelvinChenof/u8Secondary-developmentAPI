# 源码组成与依赖

本项目为 U8 与 OA 之间的委外订单集成提供二次开发代码，包含两个部分：

- **U8 接口**：C# HTTP 服务、原生 SDK 调用、工作进程隔离、接口鉴权和审核操作记录。
- **OA 适配**：基于 e-office 的委外订单同步、流程表单映射、供应商联系人查询和审核外发。

`source-inventory.json` 记录 OA 源码的路径与校验值。运行时使用的 `oa/auto-audit/hashes.json` 和 `oa/sync/source-hashes.json` 用于核对关联文件，修改相关源码后应同步更新这两个清单。

仓库提供源码和构建脚本，程序由使用者在 Windows 环境编译。构建产物的校验值应以实际编译结果为准。

`tools/Test-Repository.ps1` 提供统一验证入口，覆盖接口核心逻辑、工作进程、OA 回调、部署流程、语法解析及构建自检。测试使用模拟数据，不调用生产 U8 或 OA 数据库。

用友 SDK 为厂商依赖，不授予额外许可。本仓库由使用者从有授权的本机环境导入 DLL，DLL 被 Git 忽略。
